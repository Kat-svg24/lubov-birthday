САЙТ ДЛЯ ЛЮБОВИ — 2 НОЯБРЯ 2026
================================

1. Откройте index.html в браузере. Можно запустить его локально для просмотра.
2. Чтобы опубликовать на GitHub Pages:
   - Создайте публичный репозиторий с названием lubov-birthday.
   - Загрузите содержимое этой папки В КОРЕНЬ репозитория:
     index.html, styles.css, script.js и папку assets целиком.
   - Settings -> Pages -> Build and deployment: Deploy from a branch.
   - Branch main, folder /(root), Save.
   - Через некоторое время адрес будет: https://kat-svg24.github.io/lubov-birthday/
     (при условии что владелец аккаунта GitHub — kat-svg24).

На сайте работают:
- 4 интерактивные фотокарточки с семейными пожеланиями;
- праздничный торт: нажмите на свечу, чтобы задуть, и снова зажгите её;
- 12 сердечек, у каждого индивидуальное пожелание и свой набор анимаций;
- фотогалерея с увеличением кадров;
- письмо от детей и внуков;
- включение/пауза песни Ирины Аллегровой («С днём рождения»).

ВАЖНО: в большинстве браузеров включение музыки возможно только после
первого действия посетителя. Поэтому предусмотрена кнопка «Включить песню».

Изображения выбраны только из присланных материалов. Они не заменены
посторонними фотографиями. Некоторые присланные изображения ранее были
нейросетево обработаны — сайт их дополнительно не изменяет, кроме кадрирования,
масштабирования и сжатия для веба.

Мелодия предоставлена пользователем. При размещении на публичном сайте
ответственность за необходимые права на публикацию фонограммы несёт владелец сайта.
